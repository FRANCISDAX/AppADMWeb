📋 ¿Qué es JorFel?

JorFel es una plataforma web y PWA (Progressive Web App) diseñada para gestionar ventas, inventario, clientes, reportes y caja de forma simple y profesional. Funciona como una app instalable en celular, tablet o computadora, sin necesidad de Play Store.

📦 Módulos Principales

🛒 Punto de Venta (PDV)

  • Interfaz táctil para ventas rápidas
  • Búsqueda por nombre o código
  • Escáner de barras USB y cámara
  • Métodos: Efectivo, Yape, Plin, Transferencia, Crédito, Mixto
  • Notas de venta, boletas y facturas
  • Impresión de tickets térmicos
  • Venta a crédito con seguimiento
  • Envío a domicilio con zonas y costos
  • Embalajes: cartones, cajas, bolsas sin inventario
  • Ventas pausadas y recuperación
  • Flujo Vendedor → Cajero: vendedor envía la venta a caja, cajero cobra
  • Ventas pendientes en cola para cobro rápido

📊 Inventario

  • Control de stock por producto
  • Alertas de stock bajo y agotado
  • Kardex (historial de movimientos)
  • Ajustes de stock con motivo
  • Presentaciones de venta y compra
  • Fecha de vencimiento con alertas
  • Costo de adquisición y márgenes
  • Productos favoritos para venta rápida

💰 Turnos de Caja

  • Apertura con monto inicial
  • Cierre con arqueo automático
  • Control por usuario y caja
  • Gastos del turno (caja o transferencia)
  • Rectificación de monto inicial
  • Historial de turnos cerrados
  • Seguimiento de envíos pendientes
  • Vendedor visible en cada comprobante

📈 Reportes

  • Facturación (día, semana, mes)
  • Reporte por turnos y fechas
  • Análisis de productos
  • Ventas por vendedor
  • Consolidado de boletas
  • Registro para SUNAT (SIRE)
  • Rotación de inventario
  • Ranking de clientes frecuentes

👥 Clientes

  • Base de datos con DNI/RUC
  • Historial de compras
  • Estado de cuenta (créditos)
  • Búsqueda rápida
  • Dirección y datos de contacto
  • Ranking de clientes frecuentes

💸 Egresos / Gastos

  • Registro de gastos operativos
  • Categorías personalizables
  • Pago en caja o transferencia
  • Reporte por período

⚙️ Administración

  • Dashboard gerencial en tiempo real
  • Dashboard de operaciones
  • Gestión de usuarios y roles
  • Configuración del negocio
  • Gestión de cajas con series propias
  • Auditoría general y de caja

📱 Experiencia

  • PWA: App sin Play Store
  • Modo oscuro y claro
  • Funciona offline (consulta)
  • Actualizaciones automáticas
  • Acceso desde cualquier dispositivo

🚚 Envío a Domicilio

  • Zonas de envío configurables
  • Costos por zona
  • Seguimiento: Pendiente → En camino → Entregado
  • Dirección, referencia y notas del cliente
  • Envíos pendientes de turnos anteriores

🧠 Arqueo Inteligente

  • Diagnóstico automático de diferencias
  • Detecta ventas faltantes o duplicadas
  • Identifica confusión efectivo/transferencia
  • Alertas de gastos sin registro
  • Pistas para reconciliación rápida

📦 Plantillas Manuales

  • Plantillas de productos sin inventario
  • Cartones, cajas, bolsas, sacos
  • 1 click para agregar al carrito
  • Configuración centralizada
  • Compartido entre todos los usuarios

🚚 Proveedores

  • CRUD completo con SUNAT lookup
  • Contactos, crédito, saldo pendiente
  • Historial de compras por proveedor
  • Control de deudas y pagos
  • Comparar precios entre proveedores
  • Ranking de confiabilidad
  • Sugerencia de compra por stock bajo
  • 5 tabs: Lista, Dashboard, Compras, Precios, Ranking

🏷️ Sistema de Descuentos

  • Por producto: campo descuentoPorcentaje (0-100%)
  • Por volumen: 3×2, 2da al 50%, "Llevá 4 pagá 3", % por volumen, monto fijo
  • Por cliente: descuento frecuente automático
  • Global: descuento manual S/ o % en el PDV
  • Orden: producto → volumen → cliente → global
  • Resumen visual de descuentos aplicados
  • Integrado con pantalla del cliente

¿Por qué elegir JorFel?

JorFel no es solo un sistema de ventas. Es una solución completa que se adapta a tu negocio. Instálalo como app en tu celular, úsalo sin internet, actualízalo automáticamente y accede desde cualquier lugar. Sin costos de hardware, sin licencias complicadas, sin límites. El flujo vendedor → cajero separa quién vende de quién cobra, dando control total sobre la caja.
